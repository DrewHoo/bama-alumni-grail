The Bama Alumni Grail

One ash-gray University of Alabama Alumni crewneck — big straight-set outline ALABAMA, the university seal rising behind it, a charcoal ALUMNI ribbon below — on a made-in-USA Jerzees Super Sweats blank. It exists. One of them is being hunted.

How to read this page: the target spec is the sweatshirt in hand (photos below). Everything else is ranked by distance from it — after passing two hard gates: it has to be gray, and it has to be an L or an XL. Crimson versions of the print are kept below as comps, never as options; XXLs are not kept at all. Prices & availability as of Sep 24, 2026 — vintage listings die fast; buy buttons go to the live listing. Each card is stamped with the date it was added to this page, so the new arrivals are obvious. No affiliate links, no trackers.

Current verdict: still not listed — and the elephant print now has two live copies instead of none.

As of Sep 24, 2026, the exact print (outline ALABAMA + seal + ALUMNI banner, gray) is not live on eBay, Etsy, Poshmark, Mercari, Depop, Grailed, AlabamaVTG’s 452-product catalog, Facebook Marketplace, or the open web index. Thirty-nine new listings were judged this run. None earned a vintage card: every seal print that turned up was red, and every gray one had no seal. What changed is new production. Homefield’s seal crew, sold out since August, is back in stock in L and XL at $68, on ash. Every live vintage card was re-opened and is still for sale. The Grailed XL went back up from $48 to $54.

Three days ago the elephant-through-the-A print existed in exactly one buyable copy, and that copy was the first one ever found in a Large. Now there are two. Grailed is carrying the same device on true ash in an XL — the elephant striding through a crimson block A, CRIMSON TIDE on the ribbon, ALABAMA underneath — for $60 plus $11 shipping. It is tagged 2XL and measures 22.5″ pit to pit, which is an XL by any honest tape, so the size rule survives intact. The Hanes Beefy Large at $30 is still the better buy on price; this one exists so the decision is no longer this one or nothing.

Everything already on the board held. The Hanes L, the Russell seal L and the ash seal XL all re-verified in stock at the same prices. The Etsy laurel-seal XL moved the wrong way — $72 to $80 — which for a shirt the seller describes as yellow-stained is a card sliding down, not up. And the Birmingham Champion earned a correction: seen full-size in the listing photos it is warm oatmeal, not gray, and the circle under the arch is a script-A badge rather than the university seal. It stays on the page, ranked last, with the caveat attached. That is the same trap the tan Galt Sand set in August.

The target

Photographed in hand. The neck tag is Jerzees Super Sweats, 42-44 (a 90s Large), Made in U.S.A.; the care tag is Russell Corp, Alexander City, AL — WPL 7332, ~50/50 poly-cotton with 5% other fiber. That tag combo dates it to roughly 1988–1995.

Match checklist (in priority order)

Color hard gate
Must be a shade of gray. Ash and light heather are ideal, charcoal is viable. Everything else is an automatic pass no matter how right the print is — red/crimson, white, cream, oatmeal, sand and black are out. Checked before the graphic.
Graphic
Straight-set serif ALABAMA — charcoal-heather fill, crimson outline; circular University of Alabama seal rising behind the letters; charcoal ALUMNI ribbon banner below
Blank
Jerzees Super Sweats (Russell Corp), Made in USA — same-era Russell/Jerzees acceptable
Size hard gate
L or XL only. 42-44 (a 90s L) is ideal and a modern L–XL is fine. XXL is out — it wears too big, and no print is good enough to buy around it.
Condition
Honest wear fine; no large stains or holes
Price guide
Comps say $20–$50; up to ~$75 for a true exact match is rational grail money
